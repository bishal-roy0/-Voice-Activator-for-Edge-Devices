# ESP32-S3 firmware module

**Owner:** Member 2

This module will contain the ESP32-S3 firmware for I2S microphone capture, compatible preprocessing, local TinyML inference, wake/record/send state handling, Wi-Fi transfer, and resource measurements.

Do not choose an SDK or commit generated build output until the team records the tooling decision. Firmware must match the TinyML preprocessing contract exactly and must stream only post-wake command audio.
