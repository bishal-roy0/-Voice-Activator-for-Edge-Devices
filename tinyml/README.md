# TinyML module

**Owner:** Member 1

This module will contain reproducible dataset preparation, training, quantization, and model evaluation material for the custom wake word.

Before handing a model to firmware, document the approved preprocessing configuration, input tensor shape, output labels, threshold recommendation, model size, and evaluation evidence in `docs/interfaces.md` and `docs/testing-and-metrics.md`.

Do not commit raw recordings, participant-identifying data, or generated model binaries. Store only scripts, configuration, documentation, and safe small fixtures approved for version control.
